## Mandatory Payroll Rules

⚠️ **These are NON-NEGOTIABLE** (from memory.md)

### Formulas (EXACT order, no variations)
```
Basic = Gross × 90%
Medical = Basic × 10%
Other = Gross - Basic - Medical
Total Allowance = sum of all allowances
Taxable = Total Allowance - Medical - Unpaid Days
Deductions = sum of 8 items
Net = Allowances - Deductions
```

### Employee Verification (4-step, EVERY entry)
1. Match full name exactly
2. Verify employee ID
3. Confirm entity/company
4. Cross-check other details

**One wrong entry = affects someone's salary → ZERO tolerance**

### Salary Change Alerts
Monitor emails & Teams for:
- Promotions, increments
- Part-time transitions
- Status changes
- Extract carefully in STEP 5

### Overtime Approval (dual-approval required)
- Manager Status = "APPROVED"
- HR Status = "Moved to [MONTH] PAYROLL"
- Manual calculation cross-check mandatory

### Pending Dues Protocol
**ALWAYS ask:** "Are there pending dues?" EVERY month
- Manually tracked by HR, not in systems
- Common: new joiners on 25th
- Ask, verify, add — never skip

## Session Workflow

Each payroll session follows this structure:
1. Verify employees and basic info
2. Calculate allowances
3. Apply deductions
4. Cross-check calculations
5. Apply salary changes
6. Generate payroll report
7. Review and validate

See payroll/SESSIONS.md for detailed progress tracking.
