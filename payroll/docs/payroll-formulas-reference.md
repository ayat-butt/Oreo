# Payroll Formulas - Complete Reference

**CRITICAL:** These formulas are ESSENTIAL for accurate payroll calculations. Use these EXACTLY as written for every payroll cycle.

---

## All Payroll Formulas (Master List)

### 1. Basic Salary
```
Basic Salary = Gross Salary × 90%
```
**Example:** Gross 100,000 × 90% = 90,000 Basic Salary

---

### 2. Medical Allowance
```
Medical Allowance = Basic Salary × 10%
```
**Example:** Basic 90,000 × 10% = 9,000 Medical Allowance

---

### 3. Other Allowance
```
Other Allowance = Gross Salary - Basic Salary - Medical Allowance
```
**Example:** 100,000 - 90,000 - 9,000 = 1,000 Other Allowance

---

### 4. Total Allowance
```
Total Allowance = Basic + Medical + Other + Commute + Pending + Overtime
```
**Components:**
- Basic Salary (from Formula 1)
- Medical Allowance (from Formula 2)
- Other Allowance (from Formula 3)
- Commute Allowance (from STEP 3)
- Pending Dues (from STEP 7)
- Overtime (from STEP 6)

**Example:**
```
Basic:              90,000
Medical:             9,000
Other:               1,000
Commute:             2,000
Pending:             5,000
Overtime:            2,500
───────────────────────────
Total Allowance:   109,500
```

---

### 5. Taxable Salary
```
Taxable Salary = Total Allowance - Medical Allowance - Unpaid Days
```
**Components:**
- Total Allowance (from Formula 4)
- Medical Allowance (subtracted, as it's tax-exempt)
- Unpaid Days (from STEP 2)

**Example:**
```
Total Allowance:   109,500
- Medical Allow.:   -9,000
- Unpaid Days:      -3,000
───────────────────────────
Taxable Salary:    97,500
```

---

### 6. Total Deductions
```
Total Deductions = IT + EOBI + Advance + Abhi + Loan + BusCaro + Lunch + Unpaid Days
```

**Components:**
- **IT** = Income Tax (calculated on Taxable Salary)
- **EOBI** = Employee Old Age Benefits contribution
- **Advance** = Salary advance deduction
- **Abhi** = Abhi (insurance/benefit) deduction
- **Loan** = Loan deduction
- **BusCaro** = Bus/Transportation deduction (separate from Commute)
- **Lunch** = Lunch/Meal deduction (5,720 from STEP 4)
- **Unpaid Days** = Deduction for unpaid days (from STEP 2)

**Example:**
```
IT:                  8,000
EOBI:                2,500
Advance:             5,000
Abhi:                1,000
Loan:                3,000
BusCaro:             1,500
Lunch:               5,720
Unpaid Days:         3,000
───────────────────────────
Total Deductions:   30,220
```

---

### 7. Net Salary
```
Net Salary = Total Allowance - Total Deductions
```

**This is the FINAL amount paid to employee**

**Components:**
- Total Allowance (from Formula 4)
- Total Deductions (from Formula 6)

**Example:**
```
Total Allowance:   109,500
- Total Deduct.:   -30,220
───────────────────────────
Net Salary:         79,280
```

---

## Formula Dependency Chain

```
Gross Salary (INPUT)
    ↓
Basic Salary = Gross × 90%
    ↓
Medical Allowance = Basic × 10%
    ↓
Other Allowance = Gross - Basic - Medical
    ↓
Total Allowance = Basic + Medical + Other + Commute + Pending + Overtime
    ↓
Taxable Salary = Total Allowance - Medical - Unpaid Days
    ↓
Total Deductions = IT + EOBI + Advance + Abhi + Loan + BusCaro + Lunch + Unpaid Days
    ↓
Net Salary = Total Allowance - Total Deductions
```

---

## Order of Calculation (Critical)

**ALWAYS calculate in this order:**

1. ✅ **Basic Salary** = Gross × 90%
2. ✅ **Medical Allowance** = Basic × 10%
3. ✅ **Other Allowance** = Gross - Basic - Medical
4. ✅ **Total Allowance** = Basic + Medical + Other + Commute + Pending + Overtime
5. ✅ **Taxable Salary** = Total Allowance - Medical - Unpaid Days
6. ✅ **Total Deductions** = IT + EOBI + Advance + Abhi + Loan + BusCaro + Lunch + Unpaid Days
7. ✅ **Net Salary** = Total Allowance - Total Deductions

**DO NOT skip steps or change order - formulas depend on previous calculations**

---

## Key Formula Rules

### ⚠️ CRITICAL RULES

1. **Basic Salary is ALWAYS 90% of Gross**
   - No exceptions
   - Unless gross salary changed (STEP 5)

2. **Medical Allowance is ALWAYS 10% of Basic**
   - No exceptions
   - Unless basic salary changed

3. **Other Allowance = what's left**
   - After Basic and Medical accounted for
   - Balancing calculation

4. **Total Allowance includes variable components**
   - Commute, Pending, Overtime change monthly
   - Must recalculate fresh each month

5. **Taxable Salary excludes Medical**
   - Medical is tax-exempt
   - Unpaid days reduce taxable amount

6. **Total Deductions include ALL deductions**
   - Income Tax (IT)
   - EOBI
   - Advance deduction
   - Abhi
   - Loan deduction
   - Bus/Transportation (BusCaro)
   - Lunch/Meal (5,720 fixed)
   - Unpaid Days

7. **Net Salary is final payment**
   - Total Allowance MINUS Total Deductions
   - This is what employee receives

| **IT** | Income Tax | Calculated on Taxable Salary, varies by amount |
| **EOBI** | Employee Old Age Benefits | Statutory contribution |
| **Advance** | Salary Advance | Deduction for previous advance given |
| **Abhi** | Insurance/Benefit | Company insurance program |
| **Loan** | Loan Deduction | Deduction for employee loan |
| **BusCaro** | Bus/Transportation | Separate from Commute Allowance |
| **Lunch** | Meal Deduction | 5,720 fixed (from STEP 4) |
| **Unpaid Days** | Unpaid Days | Deduction for unpaid days (from STEP 2) |

## Verification Checklist

Before finalizing payroll, verify:

- ✅ Basic = Gross × 90% (for each employee)
- ✅ Medical = Basic × 10% (for each employee)
- ✅ Other = Gross - Basic - Medical (for each employee)
- ✅ Total Allowance = sum of 6 components (fresh each month)
- ✅ Taxable = Total Allow - Medical - Unpaid (for each employee)
- ✅ Total Deductions = sum of 8 deduction items
- ✅ Net = Total Allow - Total Deduct (final payment)
